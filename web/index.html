読み込み＝初回のダウンロードとモデル初期化（2回目以降は 0）。推論＝画像1枚の処理時間（連続実行は平均）。動画・カメラは元の解像度で表示し、推論には「処理解像度」（長辺、既定 640px）に縮めたフレームを渡す。ブラウザ実行はこの端末の性能、サーバー実行はサーバーの性能と通信を含む。

速度を測る（ベンチマーク）

決まったサンプル画像（街）で、ウォームアップ 3 回のあと指定の回数だけ推論し、中央値・p90・p95 などを実行履歴に「ベンチ」として記録する。端末ごとに同じ条件で比べられるので、CSV を書き出して並べるとよい（端末の情報は書き出すファイルに入るだけで、どこにも送らない）。「モデル入力」「実行設定」は今の設定で測る。

測るモデルを選ぶ

詳細計測中（URL の ?profile=1）: 汎用 ONNX のブラウザ実行で、演算ごとの GPU 時間を測る。計測の手間で推論が遅くなるので、端末どうしの速さの比較には使わない。結果は下の表と、実行履歴の JSON に入る。

手元の ONNX を使う

公開されているモデルのファイルを既に持っている時に、ダウンロードせずに使う。選んだファイルの SHA-256 を下のモデルのファイルと照らし、完全に一致した時だけそのモデルのファイルとしてブラウザのキャッシュに入れる（ファイルは端末の外に送らない）。一致しないファイル（自前で学習・変換したもの）は今のところ使えない。

      データと通信について

      • ブラウザで実行するモデルは、初回にこの端末へダウンロードする（モデルの横に大きさを表示。数MB〜約1.4GB）。モバイル回線では通信量に注意。100MB を超えるモデルは、初回に確認してから取得する。2回目以降はブラウザのキャッシュから読むので通信しない
      • 画像・動画・カメラの映像は、ブラウザで実行する限り端末の外に送らない（通信するのはモデルとライブラリの取得だけ）。サーバーで実行を選んだ時だけ、その画像をサーバーに送る
      • 各モデルのライセンスはモデルの説明に表示している（商用利用できないものもある）。重みは各配布元から取得する
